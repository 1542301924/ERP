## 2. 报表口径（关键概念）

报表的核心是先确定「什么算事实」，再据此聚合：

| 报表类别 | 事实来源 | 计入条件 |
|---|---|---|
| **库存类**（进销存明细 / 汇总） | `stock_ledger`（唯一事实来源） | `deleted = 0`；红冲以「再写一条反向流水」体现，**净额天然为 0**，历史可完整追溯 |
| **单据类**（收货 / 发货对账、发货成本、销售毛利） | 采购入库 / 销售出库单据 | `status = 1`（已审核）**且** `reversal_of IS NULL`（非红冲单） |

由此得出三条不变式：

1. **库存类只认流水**：`stock_ledger` 是 append-only 的；「取消审核 / 红冲」都不删原流水，而是追加反向流水，因此进销存明细表能看到完整过程，汇总表净额自动归零。
2. **单据类只认「已审核 + 非红冲单」**：被红冲的原单（`status = 9`）与被红冲产生的反向单（`reversal_of` 非空）都不计入，二者在报表中净额归零，与 P4「已审核生效」口径完全一致。
3. **数量一律按商品基本单位**（`base_qty`）计；**成本取销售出库明细的成本快照**（`cost_amount`，出库审核时按移动加权平均写入的 `unit_cost × base_qty`）。

> 进销存汇总表的**期初** = 区间开始日之前的流水净额；**本期入/出** = 区间内的流水；**期末 = 期初 + 本期入 − 本期出**。三段由同一批流水用条件聚合一次算出，因此**天然幂等**、可与明细表逐笔勾稽。

## 3. 各报表字段说明

### 3.1 进销存明细表

每笔 `stock_ledger` 一行。列：业务日期、业务类型、单据编号、商品编号、商品名称、仓库、货位、单位、入库数量、出库数量、单位成本、金额、冲销。

- **金额**：该次变动的成本额（`amount` 恒为**正数绝对金额**）。
- **冲销**：原流水 `reversal_of` 非空时标记「红冲」（正常流水为空）。
- 底部合计行给出 入库数量 / 出库数量 / 金额 合计。

### 3.2 进销存汇总表

按商品（默认）或「商品 + 仓库」聚合。列：商品编号、商品名称、[仓库]、单位、期初数量、期初金额、本期入库数量、本期入库金额、本期出库数量、本期出库金额、期末数量、期末金额。

- **勾稽关系**：`期末数量 = 期初数量 + 本期入库 − 本期出库`，金额同理。
- 只给起始日 / 只给结束日也可用：起始日之前全部计入期初，结束日之后不计入。

### 3.3 收货对账单

按供应商聚合。列：供应商、入库单数、入库数量、入库金额、应付金额、已付金额、未付金额。

- 统计范围：该供应商**已审核且非红冲**的采购入库单（`inbound_type = 采购`）。
- **入库金额** = 入库单 `total_amount` 合计；**应付 / 已付** 取自来源应付单 `ap_bill` 的 `amount` 与 `paid_amount`；**未付 = 应付 − 已付**。

### 3.4 发货对账单

按客户聚合。列：客户、出库单数、出库数量、出库金额、应收金额、已收金额、未收金额。

- 统计范围：该客户**已审核且非红冲**的销售出库单（`outbound_type = 销售`）。
- **应收 / 已收** 取自来源应收单 `ar_bill` 的 `amount` 与 `received_amount`；**未收 = 应收 − 已收**。

### 3.5 发货成本表

每张销售出库单一行。列：单据编号、业务日期、客户、商品项数、销售金额、成本金额、毛利、毛利率。

- **销售金额** = 出库明细 `amount` 合计；**成本金额** = 出库明细 `cost_amount` 合计（成本快照）；**毛利 = 销售金额 − 成本金额**；**毛利率 = 毛利 / 销售金额**（销售额为 0 时记 0）。

### 3.6 销售毛利表

按商品 / 客户 / 业务员聚合（下拉可切换）。列：[商品编号]、维度名称、销售数量、销售额、成本额、毛利、毛利率。

- 维度名称随「汇总维度」变化：按商品显示商品名（含编号列）、按客户显示客户名、按业务员显示用户姓名。
- **毛利与「发货成本表」同源**（同一批出库明细的成本快照），因此两张表的毛利合计天然一致。

## 4. 操作说明

### 4.1 通用操作

1. 在顶部筛选区选择条件（各报表展示的筛选维度不同，见 §1 表格）。
2. 点「查询」按条件重新出数；点「重置」清空全部条件并重新查询。
3. 点「导出 Excel」弹出保存对话框，导出**当前筛选条件下**的报表；导出内容 = 表头（中文标签）+ 明细行 + **加粗合计行**，数值与页面一致。

### 4.2 推荐使用顺序

1. P1 建好 商品 / 仓库 / 客户 / 供应商 主数据。
2. P2 完成采购入库、销售出库的开单与**审核**（只有审核后才写流水、才生成往来单）。
3. P5 在「报表」分组按需查看 / 导出；月末对账用「进销存汇总表」勾稽数量与金额。

## 5. 常见问题

**Q：为什么发货成本表 / 销售毛利表只有部分单据？**
只有**已审核**（`status = 1`）且**非红冲单**（`reversal_of IS NULL`）的销售出库单才计入。草稿、已红冲的原单、以及红冲产生的反向单都不计入。

**Q：进销存明细表里为什么能看到「红冲」行？**
库存流水是 append-only 的，红冲不会删原行，而是**追加一条反向流水**。因此明细表能看到完整过程；汇总表把正负相抵，净额自动为 0。

**Q：进销存汇总表的期末数量和实时库存对不上？**
两者口径不同：汇总表是**按业务日期区间**的流水聚合，实时库存（`stock_balance`）是**全时点累计**的余额。请确认筛选的日期区间是否覆盖了全部业务，且看的是同一商品 / 仓库维度。

**Q：为什么毛利表和成本表的毛利合计一致？**
两张表都取销售出库明细的成本快照 `cost_amount`，口径同源，只是聚合维度不同，因此合计必然一致。

**Q：导出的 Excel 数值和页面对不上？**
导出的是**点击导出时的筛选条件**下的结果；若页面在导出前刚改过筛选未点「查询」，请先「查询」再导出。

## 6. 数据出错如何回滚

报表是**只读派生结果**，本身不落库，因此**不需要也无法在报表层回滚**。若发现报表数据异常，应回到**事实来源**修正，修正后报表自动反映：

- **单据类报表口径错**：到 P2「采购入库 / 销售出库」页面，对相关单据执行**取消审核**（回待审核可编辑）后重新开单审核；或对已生效单据执行**红冲**（追加反向已审核单据冲平，原单标记已红冲）。
- **库存类报表口径错**：先在 P2 / P3 修正单据（取消审核 / 红冲），再在「库存」页点**重算库存余额**；`stock_ledger` 是唯一事实来源，重算幂等，多次执行结果一致。
- **往来金额（应付/已付、应收/已收）不对**：到 P4「应收管理 / 应付管理」处理收付款单（取消审核 / 红冲），或在「资金账户流水」页点**全量重算**。

> 所有回滚都遵循同一约定：**不删除历史，只追加反向事实**——取消审核把单据退回草稿，红冲追加反向单据，流水追加反向行，报表据此自动重算，永远不会出现「删历史导致对账断链」。

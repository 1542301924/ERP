- 阶段：P1（基础资料 / 主数据）
- 交付物：桌面端「基础资料」下 10 个可用页面 + Excel 模板中心

## 2. 操作说明

### 2.1 先做什么：推荐初始化顺序

1. **计量单位** —— 至少保留「个 / 件 / 箱 / kg」（系统已内置这 4 个，可直接增补）。
2. **商品类别** —— 建多级类别（如 五金 / 五金/螺丝）。
3. **仓库 → 货位** —— 先建仓库，再在货位页按仓库建货架/货位。
4. **客户 / 供应商 / 部门**。
5. **编码规则** —— 若要使用商品编号「自动生成」，请先在编码规则页建一条 `target = product` 的规则（见 §2.4）。
6. **商品管理** —— 逐个新增，或用 Excel 模板批量导入（见 §2.5）。

> 建议顺序的原因：商品的「基本单位」「类别」是必填/可选引用项，必须先存在才能录入或导入；否则导入该行会报错。

### 2.2 商品管理

- **搜索**：支持按关键字（同时匹配 商品编号 / 名称 / 条码 / 规格）、按类别、按状态筛选；「重置」清空条件。
- **新增 / 编辑**：
  - 商品编号唯一；点「自动生成」按编码规则生成（未配置规则会提示，请先见 §2.4）。
  - **基本单位必选**：库存记账口径统一为「基本单位」，务必选对。
  - 预设进价 / 售价、期初数量 / 期初成本、最低 / 最高库存（预警阈值，P3 起用于预警标色）。
- **多单位（换算）**：
  - 每个单位给一个**换算率 factor**，含义是「1 个该单位 = factor 个基本单位」。例：基本单位=个，箱的 factor=12。
  - 单据上可以按「箱」录入，系统自动折算为「个」记账（多单位出现在录入/展示层，库存一律记基本单位）。
  - 基本单位那一行由系统自动保证为 `factor=1、是否基本单位=是`，无需手工维护。
  - 可为每个单位单独设置条码与进价/售价（按单位定价）。
- **条码**：一个商品可以有多个条码（主条码 + 备用条码），扫码反查时都能命中。
- **扫码查询**：输入/粘贴条码 → 按优先级 `商品主条码 → 商品单位条码 → 商品条码表` 命中并展示商品摘要；命中单位条码时会一并显示该单位。
- **库存预览**：只读抽屉，展示该商品的库存余额与最近流水。**P1 阶段还没有库存数据**（库存在 P3 生成），因此会显示「库存数据将在 P3 阶段生成」。
- **停用 / 启用**：停用后商品不出现在新单据的选择列表，历史数据不受影响。

### 2.3 商品类别（多级树）

- 选中节点后可「编辑 / 删除 / 新增子类」。
- 系统自动维护 `path`（物化路径，形如 `/root/{id}/{id}/`），**移动节点（改上级）会级联重算其所有后代的路径**，无需手工处理。
- 删除限制：**有子类别** 或 **已被商品引用** 时不允许删除，会提示具体原因。

### 2.4 编码规则

| 字段 | 说明 |
|---|---|
| 适用对象 target | `product`（商品编号）/ `customer` / `supplier` / `doc_no`（单据号，P2 起使用） |
| 前缀 prefix | 编号前缀，如 `P` |
| 类别码 category_code | 可选的类别段，如 `HW` |
| 流水号位数 seq_len | 默认 4 → `0001` |
| 当前序号 next_seq | 下一个待用流水号 |

- 「预览」列按 `前缀 + 类别码 + 序号(补零到 seq_len)` 即时计算示例，**不会消耗序号**。
- 真正生成编号（商品管理的「自动生成」、P2 的开单）会**占用并自增**序号，且自增会记录到同步日志。

### 2.5 Excel 模板中心

**（1）模板下载**（共 6 个）

| 模板 | 可导入 |
|---|---|
| 商品档案 | ✅ |
| 客户档案 | ✅ |
| 供应商档案 | ✅ |
| 期初库存 | ✅ |
| 采购入库单 | ❌（P2 开放，当前仅可下载模板） |
| 销售出库单 | ❌（P2 开放，当前仅可下载模板） |

**（2）导入流程**：选择模板 → 「选择文件」(.xlsx) → 「开始导入」→ 查看结果（总数 / 成功 / 失败）与错误行明细。

**（3）逐行报错规则**：导入**逐行独立**处理，出错的行只跳过该行，**其余行照常导入**（不会整批回滚）。

- **错误行号 = Excel 中的实际行号**（表头是第 1 行，第一条数据是第 2 行）。界面上标注为「Excel 行号」，请直接对着 Excel 左侧行号定位。
- 表头匹配容错：允许列名前后有空格、允许带 `*` 号。

**商品档案导入校验规则**

| 情况 | 结果 |
|---|---|
| 商品编号 或 商品名称 为空 | 该行失败 |
| **同一文件内商品编号重复** | **所有涉及重复编号的行全部失败**（不做部分导入） |
| 商品编号与库中已有商品重复 | 该行失败（导入只新增，不覆盖已有商品） |
| 基本单位名称在「计量单位」中不存在 | 该行失败 |
| 类别编码在「商品类别」中不存在 | 该行失败 |
| 成功 | 新增商品，并自动为其创建「基本单位 ⇒ factor=1」的换算行 |

**期初库存导入**：按「商品编号」匹配已有商品，写入 `期初数量 / 期初成本`；编号找不到则失败。**P1 只写主数据字段，期初流水在 P3 生成。**

**（4）导出**：选择 商品 / 客户 / 供应商 / 计量单位 / 仓库 / 部门 → 「导出 Excel」，选择保存位置即可。

## 3. 常见问题

**Q1：点「自动生成」提示未配置编码规则？**
先去「编码规则」建一条 `target = product` 的规则（如 前缀 `P`、位数 4）；或手工输入商品编号。

**Q2：导入 100 行只成功 98 行，报 2 行错？**
正常。请看结果里的错误表：每行给出行号与原因；修正 Excel 里的这两行后，**重新导入整份文件即可**（已成功的 98 行会因「编号已存在」而报重复——此时请只保留需要补录的行再导入，或改用「编辑」逐个修改）。

> 更稳妥的做法：导出/清点已成功行，把失败行单独放一份新文件重导。

**Q3：导入报「基本单位不存在」/「类别编码不存在」？**
先建好对应的「计量单位」和「商品类别」再导入（名称/编码必须完全一致，注意大小写与空格）。

**Q4：导入后商品有，但「库存预览」是空的？**
正常。P1 不产生库存；库存余额与流水在 P3 阶段按流水重算生成。

**Q5：为什么「箱」的数量和库存数量对不上？**
库存一律按**基本单位**记账。按「箱」录入时系统自动乘以换算率折成基本单位（1 箱 = factor × 基本单位）。

**Q6：删除类别提示不允许？**
该类别下仍有子类别，或已被商品引用。先移动/删除下游数据，或改为「停用」。

**Q7：停用了商品，历史单据会受影响吗？**
不会。停用只影响**新单据**的选择列表；已发生的数据与库存不受影响。

**Q8：数据存在哪里？多台电脑会互相覆盖吗？**
每个桌面端各自一份本地库（用户数据目录下的 `inventory.db`）。P1 阶段**还没有同步**，多端数据互相独立，同步在 P7 联调。**P1 请勿在多于一台电脑上同时录入同一批数据。**

## 4. 数据出错如何回滚

### 4.1 删除/停用类

- 本阶段所有「删除」都是**软删除**（`deleted=1`），数据**仍在库中**，不会被物理清掉，也不影响同步（P7 会把删除作为一次变更同步出去）。
- 目前**界面未提供「恢复已删除」入口**（回收站计划在后续版本提供）。误删后的处置顺序：
  1. 若只是「停用」，在列表把状态改回「启用」即可，无副作用。
  2. 若误删了主数据，先确认它是否被单据引用；然后用下面的「备份恢复」或请管理员把该行 `deleted` 置回 `0`。

### 4.2 误导入一批数据

- 导入**逐行独立**，没有「一键撤销导入」。可回滚的抓手：
  1. 用「导出」把刚导入的商品导出来，核对范围；
  2. 对误导入的商品逐个「删除」（软删除，可后续恢复）或「停用」（更安全，保留记录）；
  3. P1 阶段导入**不会产生库存流水、应收应付**，因此误导入**不会污染库存与账**，影响范围仅限主数据本身。

### 4.3 备份 / 恢复（当前可用的兜底手段）

- P1 尚未提供界面化备份（备份中心计划在 P3 接入）。**建议在批量导入前手动备份数据库文件**：
  - 退出桌面端后，复制用户数据目录下的 `inventory.db`（Windows 通常位于 `%APPDATA%\<应用名>\` 下）；
  - 出错时：退出程序 → 用备份文件覆盖 `inventory.db` → 重新启动。
- 若已启用 WAL 模式，请连同一目录下的 `inventory.db-wal`、`inventory.db-shm` 一并处理（退出程序后 WAL 通常已合并）。

### 4.4 编号序号跑偏（next_seq 被消耗过多）

- 若某次误点「自动生成」或测试消耗了序号，直接在「编码规则」把 `当前序号` 手工改回期望值即可；系统只保证**不重复**，不保证连续。
